💼 Projeto profissional · Vesti Em produção

Auditoria Automática de Faturamento

Conciliação diária entre o gateway de pagamentos e a planilha de controle.

Antes, conferir se cada cliente foi cobrado corretamente era um trabalho manual, linha por linha. Construí uma rotina que, todo dia de madrugada, busca as faturas de várias contas no gateway de pagamentos, cruza com a planilha de planos e gera um relatório com tudo o que não bate.

Funcionalidades

  • Busca automática de faturas em múltiplas contas via API
  • Cruzamento por documento (CPF/CNPJ), com nome como alternativa
  • Detecção de divergências: valor, ausência, status e vencimento
  • Coluna de “situação” explicando cada caso em linguagem simples
  • Resumo executivo e resumo por cliente gerados automaticamente
  • Agendamento diário na nuvem, sem precisar de computador ligado
  • Python
  • GitHub Actions
  • API REST
  • Google Sheets API
  • n8n

🔒 Código e dados confidenciais. Descrição genérica, sem informações reais.

💼 Projeto profissional · Vesti Em produção

Painel de Inadimplência

Faturas vencidas organizadas por conta, atualizadas todo dia.

Um painel web compartilhado com o time que mostra quais clientes estão com pagamentos em atraso, há quantos dias e em qual conta. Ele se atualiza sozinho uma vez por dia e virou a referência da equipe para cobranças e bloqueios.

Funcionalidades

  • Agrupamento por conta, com busca e filtros por vencimento
  • Regras de negócio para ignorar casos antigos ou já tratados
  • Histórico de faturas canceladas visível por alguns dias
  • Aba de anotações colaborativas para o time registrar contatos
  • Atualização automática diária com proteção contra execução duplicada
  • Python
  • JavaScript
  • HTML/CSS
  • GitHub Actions
  • API REST

🔒 Código e dados confidenciais. Descrição genérica, sem informações reais.
