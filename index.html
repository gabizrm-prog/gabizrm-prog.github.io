01

Auditoria de Faturamento

Confere, toda madrugada, se cada cliente foi cobrado do jeito certo.

o problema

Para saber se cada cliente estava sendo cobrado certo, era preciso comparar à mão o sistema de pagamentos com a planilha, cliente por cliente. A conferência levava uma semana. Um fluxo antigo no n8n tentava ajudar, mas falhava sem avisar.

→
como resolvi

Criei uma rotina em Python que roda sozinha toda madrugada no GitHub Actions. Ela busca as faturas de todas as contas pela API, cruza com a planilha por CPF/CNPJ e escreve na planilha só o que não bate, com um resumo para o time.

Ponto como era antes como é agora
Tempo para ficar pronta antes1 semana agora1 noite, sem ninguém
Como era feita antesÀ mão, cliente por cliente agoraAutomática, todas as contas de uma vez
O que o time recebe antesA planilha inteira para revisar agoraSó as diferenças, explicadas em linguagem simples
Confiabilidade antesFluxo no n8n que falhava sem avisar agoraCódigo em Python, versionado no GitHub

02

Painel de Inadimplência

Mostra quais clientes estão com pagamento atrasado, sempre com dados do dia.

o problema

A lista de clientes com pagamento atrasado ficava numa planilha atualizada à mão, uma vez por semana. Cada atualização levava cerca de 3 horas. Como os dados podiam ter até uma semana de atraso, aconteciam cobranças erradas.

→
como resolvi

Fiz uma rotina que roda todo dia: coleta os dados, aplica as regras do time para ignorar casos já resolvidos e publica um painel web com busca, filtros e anotações sobre cada cliente.

Ponto como era antes como é agora

Tempo gasto antesCerca de 3 horas agora4 minutos, sem ninguém
Dados antesAté 1 semana de atraso agoraSempre do dia
Resultado antesCobranças erradas agoraReferência do time, com anotações em cada contato

03

Faturamento Mensal

Gera as faturas do mês sozinho, a partir do uso de cada cliente.

o problema

Em um dos produtos da empresa, cada cliente paga conforme quantos usuários usaram a plataforma no mês. Os dados vinham do Power BI, eram somados à mão na planilha e cada fatura era criada uma por uma. Um número digitado errado virava cobrança errada.

→
como resolvi

Criei uma rotina que percebe quando o relatório do mês é colado na planilha, calcula o valor de cada cliente (com valor mínimo), cria todas as faturas pela API e grava o link de cada uma na planilha. Se algo não bate, ela não cobra ninguém e avisa. Também fiz um painel que mostra quem já pagou.

Ponto como era antes como é agora
O que precisa fazer antesSomar e criar cada fatura à mão agoraSó colar o relatório do mês
Cálculo dos valores antesCliente por cliente na planilha agoraAutomático, com valor mínimo
Erros antesUm número errado virava cobrança errada agoraSe algo não bate, nada é enviado e chega um aviso
Acompanhamento antesConferir fatura por fatura agoraPainel mostra quem já pagou
