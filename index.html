01 pronto

Auditoria Automática de Faturamento

Uma rotina que confere, toda madrugada, se cada cliente foi cobrado do jeito certo.

antes
  • A auditoria levava uma semana inteira para ficar pronta
  • Conferência manual, cliente por cliente, entre o sistema de pagamentos e a planilha
  • Um fluxo antigo no n8n que falhava sem avisar
→
depois
  • Roda sozinha toda madrugada: o relatório já está pronto quando o time chega
  • Mostra só o que não bate, explicado em linguagem simples
  • Migrei para Python + GitHub Actions: estável, versionado e fácil de manter

Como funciona: busca as faturas de várias contas via API, cruza por CPF/CNPJ (com nome como reserva) e escreve o resultado e um resumo executivo direto na planilha do time.

  • Python
  • GitHub Actions
  • API REST
  • Google Sheets API
  • n8n

código e dados confidenciais · descrição genérica

02 pronto

Painel de Inadimplência

Transformei uma planilha manual em um painel web que se atualiza sozinho todos os dias.

antes
  • Uma planilha atualizada à mão uma vez por semana
  • Cada atualização levava cerca de 3 horas
  • Com dados de até uma semana atrás, aconteciam cobranças erradas
→
depois
  • Atualização automática e diária, sem nenhuma hora de trabalho manual
  • Dados sempre do dia, evitando as cobranças erradas causadas por informação desatualizada
  • Virou a referência do time, com anotações colaborativas sobre cada contato

Como funciona: uma rotina diária coleta os dados, aplica regras de negócio para ignorar casos já tratados e publica o painel com busca, filtros e trava contra execução duplicada.

  • Python
  • JavaScript
  • HTML/CSS
  • GitHub Actions
  • API REST
